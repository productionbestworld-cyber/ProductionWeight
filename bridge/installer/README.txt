============================================
   BWP Scale Bridge - คู่มือการติดตั้ง
============================================

วิธีติดตั้ง:
1. คลิกขวาที่ install.bat → Run as administrator
2. รอ ~5 วินาที จะมี browser เปิดที่ http://localhost:8080
3. เลือก COM port + Baud rate (9600 ส่วนใหญ่) → กดบันทึก
4. เสร็จ! Bridge จะเริ่มทำงานทันที และ Auto-start ทุกครั้งที่เปิดเครื่อง

วิธีถอนการติดตั้ง:
- คลิกขวาที่ uninstall.bat → Run as administrator

ไม่ต้องติดตั้ง Node.js หรืออะไรเพิ่ม — ใช้ได้เลย

============================================
   วิธีใช้กับ Web App
============================================

หาก Bridge อยู่เครื่องนี้ + เปิด Web App เครื่องนี้:
- Web App จะเชื่อมต่ออัตโนมัติ

หาก Bridge อยู่อีกเครื่อง + เปิด Web App เครื่องอื่น:
1. หา IP ของเครื่องที่ติดตั้ง Bridge (พิมพ์ ipconfig ใน cmd)
2. ใน Web App หน้าชั่ง → กดปุ่ม ⚙
3. ใส่: ws://<IP>:8080  (เช่น ws://192.168.1.100:8080)
4. OK

============================================
   ปัญหาที่พบบ่อย
============================================

❌ ค่าน้ำหนักไม่ขึ้น
→ เช็คใน http://localhost:8080 ว่าเลือก COM port ถูกหรือไม่
→ ลองเปลี่ยน Baud rate (1200, 2400, 4800, 9600, 19200)

❌ เข้าจากเครื่องอื่นไม่ได้
→ เช็คว่า install.bat รัน as Administrator แล้ว
→ ตรวจสอบ Firewall: control firewall.cpl
