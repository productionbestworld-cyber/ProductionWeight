# เช็กลิสต์เดินคุยหน้างาน — ก่อนออกแบบ mini-ERP

**วิธีใช้:** ปริ้นแยกแผนกละแผ่น ไปนั่งคุยที่หน้างานจริง ไม่ใช่ในห้องประชุม
คุยแผนกละ 30–45 นาที กับ **หัวหน้ากะ 1 + คนทำจริง 1** (ต้องมีคนทำจริงด้วยเสมอ)

**กติกาการถาม 3 ข้อ**
1. ขอ **ดูของจริง** ทุกครั้ง — "ขอดูใบนั้นหน่อย" ดีกว่าให้เขาเล่า
2. ถามหา **เคสที่พัง** ไม่ใช่เคสปกติ — "ครั้งล่าสุดที่ตัวเลขไม่ตรง เกิดอะไรขึ้น"
3. อย่าถามว่า "อยากได้ระบบแบบไหน" — เขาจะตอบสิ่งที่เขาคิดว่าคุณอยากได้ยิน

---

## ส่วนที่ 0 — ถามทุกแผนกเหมือนกัน (ห้ามข้าม)

- [ ] วันนี้แผนกนี้ใช้ **กระดาษกี่ใบ** ขอดูทุกใบ ถ่ายรูปเก็บไว้
- [ ] แต่ละใบ: **ใครออก → ใครกรอก → ใครเซ็น → สุดท้ายใบไปอยู่ไหน**
- [ ] ในใบนั้น **ช่องไหนที่ไม่เคยมีใครกรอก** (วงไว้ = ตัดทิ้งได้)
- [ ] มีอะไรที่ **จดใส่สมุดส่วนตัว / ไลน์กลุ่ม / กระดานไวท์บอร์ด** แทนที่จะลงใบไหม (นี่คือของจริงที่ระบบต้องรองรับ)
- [ ] ข้อมูลอะไรที่ต้อง **คีย์ซ้ำ** จากใบก่อนหน้า
- [ ] ตอน **ทำผิด** แก้ยังไง ต้องขอใครก่อน ใช้เวลานานแค่ไหน
- [ ] เดือนที่แล้ว **ตัวเลขไม่ตรง** กี่ครั้ง แต่ละครั้งรู้ตัวตอนไหน (ทันที / สิ้นวัน / ตอนลูกค้าโทรมา)
- [ ] มีมือถือ/แท็บเล็ต/สแกนเนอร์ตรงจุดนี้ไหม **สัญญาณเน็ตติดไหม** (เดินไปเช็กจริง อย่าเชื่อคำตอบ)
- [ ] คนในแผนกนี้ **อายุ/ความคุ้นมือถือ** ประมาณไหน มีใครอ่านหนังสือไม่คล่องไหม
- [ ] ถ้าระบบล่ม 2 ชั่วโมง แผนกนี้ทำงานต่อยังไง

---

## แผนกขาย

- [ ] ออเดอร์เข้ามาทางไหน (ไลน์ / โทร / อีเมล / PO ลูกค้า) สัดส่วนประมาณเท่าไหร่
- [ ] มีใบสั่งขายเป็นทางการไหม ขอดู ถ้าไม่มี — แล้วผลิตรู้ได้ยังไงว่าต้องทำอะไร
- [ ] ตอนรับออเดอร์ **รู้ได้ยังไงว่าของในคลังพอ** ถามใคร ใช้เวลานานแค่ไหน
- [ ] ลูกค้าสั่งเป็น **กิโล หรือ ม้วน หรือ ชิ้น** ตัวไหนคือตัวที่ใช้วางบิลจริง
- [ ] ยอมส่งขาด/เกินได้กี่ % (tolerance) ใครเป็นคนตัดสิน
- [ ] ราคา — ต่อลูกค้าต่อสินค้าคงที่ไหม หรือต่อรองทุกครั้ง เก็บที่ไหน
- [ ] **ใครบ้างที่ห้ามเห็นราคา**
- [ ] ลูกค้าเปลี่ยนใจ/เลื่อนของกลางคัน บ่อยแค่ไหน แจ้งผลิตยังไง
- [ ] ลูกค้าเจ้าเดียวมีหลายสาขา/หลายที่ส่ง ใช่ไหม (ระบบมี `cust_branch` อยู่แล้ว — ใช้จริงไหม)
- [ ] ตอนนี้ตอบลูกค้าว่า "ของถึงไหนแล้ว" ยังไง ใช้เวลากี่นาที

## จัดซื้อ

- [ ] รู้ได้ยังไงว่าต้องซื้อ (คนบอก / ดูของหมด / มีจุดสั่งซื้อ)
- [ ] ขอดู ใบขอซื้อ (PR) และ ใบสั่งซื้อ (PO) ถ้ามี — ใครอนุมัติ วงเงินเท่าไหร่ต้องขึ้นถึงใคร
- [ ] ซื้ออะไรบ้าง (เม็ด / มาสเตอร์แบตช์ / แกน / กล่อง / หมึก) แต่ละอย่างสั่งล่วงหน้ากี่วัน
- [ ] ซัพพลายเออร์ต่อของ 1 อย่าง มีกี่เจ้า เลือกยังไง
- [ ] **ของมาถึงแล้วใครรับ นับยังไง ถ้าของมาไม่ครบ/ไม่ตรงสเปกทำยังไง**
- [ ] เม็ดพลาสติกมี **ล็อต** ไหม ผูกล็อตกับงานผลิตได้ไหม (สำคัญมากตอน QC ไล่ย้อนของเสีย)
- [ ] เก็บสต๊อกวัตถุดิบไว้กี่วัน เคยขาดจนหยุดเครื่องไหม ครั้งล่าสุดเมื่อไหร่

## วางแผน / RD (แทรกงาน)

- [ ] ตอนนี้แผนผลิตอยู่ที่ไหน (Excel / กระดาน / ในหัว) ขอดูของจริง
- [ ] วางแผนล่วงหน้ากี่วัน ปรับแผนบ่อยแค่ไหน
- [ ] จัดคิวเครื่องยังไง — ดูอะไรบ้าง (สี / ความหนา / หน้ากว้าง / วันส่ง)
- [ ] **งานแทรก**: เดือนละกี่ครั้ง ใครสั่งแทรกได้บ้าง ต้องขออนุมัติไหม
- [ ] เวลาแทรก งานเดิมที่โดนเบียดไปทำยังไง มีใครรู้บ้าง
- [ ] **งาน RD / ตัวอย่าง**: เดือนละกี่งาน ใครขอ ใช้เม็ดจากไหน ตัดสต๊อกไหม
- [ ] ของ RD ที่ทำเสร็จเก็บไว้ไหน ถ้าลูกค้าอนุมัติแล้วกลายเป็นสินค้าปกติยังไง
- [ ] มี **สูตร (BOM)** เขียนไว้ไหม ใครรู้สูตร ถ้าคนนั้นลาป่วยเกิดอะไรขึ้น
- [ ] กำลังผลิตต่อเครื่องต่อกะ ประมาณเท่าไหร่ ใช้ตัวเลขนี้วางแผนจริงไหม
- [ ] เปลี่ยนงานบนเครื่อง (setup) ใช้เวลากี่นาที เสียเม็ดกี่กิโล

## ผลิต — เป่า *(มีระบบแล้ว — ถามหาสิ่งที่ยังหลุด)*

- [ ] วันนี้ยังมีอะไรที่ **จดกระดาษคู่กับระบบ** อยู่บ้าง เพราะอะไร
- [ ] เศษ/ของเสียตอนเป่า ตอนนี้บันทึกที่ไหน ชั่งไหม เอาไปไหนต่อ
- [ ] เม็ดที่เบิกมาเข้าเครื่อง มีการบันทึกไหม (ถ้าไม่มี = คำนวณ yield จริงไม่ได้)
- [ ] เครื่องหยุด/เสีย บันทึกที่ไหน
- [ ] ม้วนที่เป่าเสร็จ ไปกองตรงไหน ใครเป็นคนย้าย รู้ได้ยังไงว่าม้วนไหนไปกรอ/ไปพิมพ์/ไปคลัง

## ผลิต — กรอ *(มีระบบแล้ว)*

- [ ] ตอนกรอ **ยิงป้ายม้วนแม่จริงไหม** หรือคีย์เลขเอง
- [ ] 1 ม้วนแม่ กรอได้กี่ลูก ตัดทิ้งหัว-ท้ายกี่กิโล บันทึกไหม
- [ ] เอาม้วนแม่หลายม้วนมาต่อกันในลูกเดียวไหม (ถ้าใช่ ระบบต้องรองรับ many-to-many)
- [ ] กรอแล้วน้ำหนักไม่ตรงกับแม่ ปกติต่างกี่ % ถือว่าปกติ
- [ ] งานกรอที่ค้างอยู่ตอนนี้กี่ม้วน รู้จากไหน

## ผลิต — พิมพ์ *(ยังไม่มีระบบ)*

- [ ] รับงานพิมพ์มายังไง รู้ได้ยังไงว่าพิมพ์บล็อกไหน สีอะไร
- [ ] **บล็อก/เพลท** เก็บที่ไหน ใครดูแล มีทะเบียนไหม ของลูกค้าหรือของเรา
- [ ] หมึกเบิกยังไง บันทึกไหม
- [ ] ตั้งเครื่อง/ปรับสี เสียฟิล์มกี่กิโลต่องาน บันทึกไหม
- [ ] เทียบสีกับอะไร (ตัวอย่างที่ลูกค้าอนุมัติ?) ใครเป็นคนตัดสินว่าผ่าน
- [ ] ม้วนเข้า 1 ม้วน ออกมากี่ม้วน ชั่งทั้งเข้าและออกไหม
- [ ] งานพิมพ์เสีย เอาไปกรอใหม่ได้ไหม หรือทิ้งอย่างเดียว

## QC *(ยังไม่มีระบบเต็ม)*

- [ ] ตอนนี้ตรวจตรงไหนบ้าง (หลังเป่า / หลังกรอ / หลังพิมพ์ / ก่อนส่ง)
- [ ] ตรวจ **ทุกม้วน หรือ สุ่ม** สุ่มกี่ % ใครกำหนด
- [ ] ตรวจอะไรบ้าง ขอดูใบตรวจ + เกณฑ์ผ่าน/ไม่ผ่านเป็นตัวเลข
- [ ] **ขอรายชื่อชนิดของเสียทั้งหมด** (จะเอาไปทำ dropdown — หน้างานห้ามพิมพ์เอง)
- [ ] เจอของเสียแล้วทำไง — กรอใหม่ / ลดเกรด / ทิ้ง ใครตัดสิน
- [ ] มีของ **"รอตัดสิน" (hold)** ไหม กองไว้ตรงไหน กันคนหยิบไปส่งลูกค้ายังไง
- [ ] **ลูกค้าเคลม** ปีละกี่ครั้ง ตอนเคลมมา ไล่ย้อนหาล็อต/ม้วน/เม็ดได้ไหม ใช้เวลากี่วัน
- [ ] ต้องเก็บตัวอย่าง (retain sample) ไหม เก็บกี่เดือน
- [ ] ต้องออกใบรับรอง (COA) ให้ลูกค้าไหม ขอดูตัวอย่าง
- [ ] ถ่ายรูปของเสียไหม เก็บไว้ไหน

## คลัง

- [ ] คลังแบ่งเป็นกี่โซน มีป้ายตำแหน่งไหม (ถ้าไม่มี ต้องทำก่อน)
- [ ] **ตอนนี้รู้ยอดคงเหลือจากอะไร** ตรงกับของจริงไหม เช็กสต๊อกบ่อยแค่ไหน
- [ ] ครั้งล่าสุดที่นับสต๊อก ต่างจากในระบบกี่ %
- [ ] รับของเข้าคลัง ใครเป็นคนบันทึก ตอนไหน
- [ ] เบิกของออก ต้องมีใบเบิกไหม ใครเซ็น
- [ ] จัดของส่งลูกค้ายังไง — เลือกม้วนจากอะไร (FIFO? ตามล็อต? ตามที่หยิบง่าย?)
- [ ] **ขอดูใบส่งของ** ต้องมีอะไรบ้าง ลูกค้าเซ็นคืนไหม เก็บใบคืนที่ไหน
- [ ] ของที่ลูกค้าตีกลับ เข้าไปไหน บันทึกยังไง
- [ ] ของค้างสต๊อกนานเกิน 6 เดือน รู้ไหมว่ามีอะไรบ้าง

---

## สิ่งที่ต้องได้กลับมาหลังเดินครบ (ถ้าไม่ได้ 4 อย่างนี้ = ยังไม่จบ)

1. **รูปถ่ายเอกสารกระดาษทุกใบ** ที่ใช้อยู่จริง
2. **รายชื่อชนิดของเสีย** ทั้งหมดจาก QC + แต่ละแผนก
3. **ผังตำแหน่งคลัง** + ชื่อโซนที่ตกลงกันแล้ว (เอาไปใส่ตาราง `locations` ตรง ๆ)
4. **รายชื่อคน + แผนก + ว่าใครควรเห็นราคาบ้าง** (เอาไปทำ `user_roles`)

## ธงแดง — ถ้าเจอข้อไหน ต้องแก้เรื่องคนก่อน อย่าเพิ่งเขียนโค้ด

- ไม่มีใครรู้ว่ายอดคลังจริงเท่าไหร่ และไม่มีใครเดือดร้อน
- หัวหน้าบอกอย่าง คนทำจริงบอกอีกอย่าง
- "ก็จำเอา" เป็นคำตอบของขั้นตอนสำคัญ
- มีคนเดียวในโรงงานที่รู้เรื่องนี้ และเขาไม่ยอมบอก
