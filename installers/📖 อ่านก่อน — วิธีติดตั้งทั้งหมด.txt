================================================================
   BWP — ระบบชั่งน้ำหนักม้วน : วิธีติดตั้งทั้งหมด (อ่านก่อน)
================================================================

ในโฟลเดอร์นี้มีตัวติดตั้ง 2 ชุด — ติดตั้งตามความต้องการของเครื่องนั้นๆ


┌──────────────────────────────────────────────────────────────┐
│  มี 2 อย่าง ต่างกันยังไง?                                      │
└──────────────────────────────────────────────────────────────┘

  1) BWPApp-Package         = "ตัวแอป" (ไอคอนเปิดระบบชั่ง)
                              ➜ ลงทุกเครื่องที่ต้องใช้งานระบบ

  2) BWPScaleBridge-Package = "ตัวต่อเครื่องชั่ง" (อ่านน้ำหนักจาก COM)
                              ➜ ลงเฉพาะเครื่องที่ "เสียบสายเครื่องชั่ง"


┌──────────────────────────────────────────────────────────────┐
│  ติดตั้งเครื่องไหน ลงอะไรบ้าง?                                 │
└──────────────────────────────────────────────────────────────┘

  • เครื่องที่ต่อเครื่องชั่ง (เครื่องชั่งจริง)
        ➜ ลงทั้ง 2 ชุด  (แอป + Bridge)

  • เครื่องที่แค่ดูข้อมูล/แดชบอร์ด (ไม่ได้ต่อเครื่องชั่ง)
        ➜ ลงแค่ชุด 1 (แอป) พอ


┌──────────────────────────────────────────────────────────────┐
│  วิธีติดตั้ง (คลิกเดียวจบทั้งคู่)                              │
└──────────────────────────────────────────────────────────────┘

  ▶ ตัวแอป (BWPApp-Package)
     1. เข้าโฟลเดอร์ BWPApp-Package
     2. ดับเบิลคลิก  ติดตั้งแอป-คลิกเดียว.bat
     3. กด Yes (UAC)
     ➜ ได้ไอคอน "BWP ระบบชั่ง" บนหน้าจอ → ดับเบิลคลิกเปิดระบบได้เลย

  ▶ ตัวต่อเครื่องชั่ง (BWPScaleBridge-Package)
     1. เข้าโฟลเดอร์ BWPScaleBridge-Package
     2. ดับเบิลคลิก  ติดตั้ง-คลิกเดียว.bat
     3. กด Yes (UAC)
     ➜ ได้ไอคอน "BWP Scale" + เปิดหน้าตั้งค่า COM port ให้
     4. กด ⚙ ตั้งค่า COM port → เลือกพอร์ตเครื่องชั่ง → บันทึก (ทำครั้งเดียว)


┌──────────────────────────────────────────────────────────────┐
│  ลำดับแนะนำ (เครื่องที่ต่อเครื่องชั่ง)                         │
└──────────────────────────────────────────────────────────────┘

  1. ลง Bridge ก่อน → ตั้งค่า COM port ให้ค่าน้ำหนักขึ้น
  2. ลงแอป → เปิดไอคอน → เลือกแผนก → ใส่ PIN → เริ่มชั่งได้เลย


┌──────────────────────────────────────────────────────────────┐
│  สิ่งที่เครื่องต้องมี                                          │
└──────────────────────────────────────────────────────────────┘

  • Google Chrome (หรือ Microsoft Edge)        [จำเป็น]
  • อินเทอร์เน็ต (ข้อมูลอยู่บนคลาวด์)            [จำเป็น]
  • สาย/พอร์ต COM ของเครื่องชั่ง                [เฉพาะเครื่องที่ต่อชั่ง]


┌──────────────────────────────────────────────────────────────┐
│  PIN เริ่มต้น                                                  │
└──────────────────────────────────────────────────────────────┘

  แผนกเป่า = 1111   |  แผนกพิมพ์ = 2222   |  แผนกกรอ = 3333
  ผจก (Admin / พิจารณาม้วนกรอ / NC) = 9999
  (เปลี่ยนได้ที่  Admin → เปลี่ยน PIN)


┌──────────────────────────────────────────────────────────────┐
│  ถอนการติดตั้ง                                                 │
└──────────────────────────────────────────────────────────────┘

  • แอป   ➜ BWPApp-Package\ถอนการติดตั้ง.bat
  • Bridge ➜ BWPScaleBridge-Package\ถอนการติดตั้ง-คลิกเดียว.bat
